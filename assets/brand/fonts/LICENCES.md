# Font licences

Fonts bundled under `assets/brand/fonts/` are SIL Open Font Licence 1.1 (OFL-1.1).

| File | Family | Weight | Upstream | Licence file |
|---|---|---|---|---|
| `SpaceGrotesk-SemiBold.ttf` | Space Grotesk | 600 | https://github.com/floriankarsten/space-grotesk | `SpaceGrotesk-OFL.txt` |
| `SpaceGrotesk-Medium.ttf` | Space Grotesk | 500 | https://github.com/floriankarsten/space-grotesk | `SpaceGrotesk-OFL.txt` |
| `JetBrainsMono-Medium.ttf` | JetBrains Mono | 500 | https://github.com/JetBrains/JetBrainsMono | `JetBrainsMono-OFL.txt` |

Wordmark SVGs outline Space Grotesk into paths so runtime use of the TTF is optional.
JetBrains Mono is for diagram and CLI labels (`ls`, `do`).
